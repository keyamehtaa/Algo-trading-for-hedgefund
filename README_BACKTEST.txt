Backtesting Results – BatraHedge Hackathon

Files included:
1) raw_backtest_results.csv
   - Candle-wise signals, returns, cumulative performance

2) trade_log.csv
   - Trade-level details including entry time, exit time, and P&L

3) config.json
   - Strategy parameters used for the backtest (MA periods, timeframe)

All results are generated using the Moving Average Crossover strategy
implemented in algo_backtest.py.
